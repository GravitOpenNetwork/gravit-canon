# EXP-HP-002 — Adversarial Opacity (planned)

**Status:** Design only  

## Intent

Probe the principle:

> Opacity of representation is permitted; opacity of accountability is not.

An adversary attempts to hide consequential intent inside non-human representations while still producing syntactically valid epistemic commitments. The experiment measures whether the Semantic Boundary + Human Authority Invariant can still force a human decision gate or force rejection.
