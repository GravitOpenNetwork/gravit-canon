# EXP-HP-001 — Semantic Space Simulation (planned)

**Status:** Design only  
**Normative force:** None  

## Intent

Construct three artificial agents with deliberately different representational spaces:

- Agent A — symbolic  
- Agent B — vector  
- Agent C — colour-coded / spectral  

All receive the same task. Each produces a claim packaged as an epistemic commitment \(K_i(c)\). Human observers do not receive the raw native representations. Validators assess compatibility of commitments and a reliability state is computed. Execution is gated by the Human Authority Invariant.

## Success criteria (research)

1. Claims can be verified for compatibility without full translation into natural language.  
2. Fail-closed behaviour is demonstrable when \(H(a)\) is absent.  
3. Adversarial injection of opaque but non-accountable claims is detectable via provenance / consistency checks.
